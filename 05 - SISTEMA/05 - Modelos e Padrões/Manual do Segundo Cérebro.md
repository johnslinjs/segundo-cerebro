# Manual do Segundo Cérebro

> Este é o manual de operação do sistema. Consulte-o para entender a arquitetura, saber onde registrar informações e manter o cofre consistente.

## Comece por aqui
1. Para registrar algo rapidamente, use [[00 - ENTRADA/Captura rápida]].
2. Para entender as áreas, consulte [[05 - SISTEMA/05 - Modelos e Padrões/Guia de pastas e áreas]].
3. Para aprender o fluxo de processamento, consulte [[05 - SISTEMA/05 - Modelos e Padrões/Como processar a Entrada - CODE]].
4. Para criar notas confiáveis, consulte [[05 - SISTEMA/05 - Modelos e Padrões/Como registrar informações e fontes]].
5. Para entender a relação entre Obsidian, Engram e GitHub, consulte [[05 - SISTEMA/05 - Modelos e Padrões/Obsidian, Engram e GitHub - funcionamento]].

## Princípios operacionais
- Capture primeiro; classifique depois.
- Preserve a fonte original.
- Uma nota deve ter propósito claro.
- Use links para conectar notas relacionadas.
- Não crie duplicatas quando um link resolve.
- Diferencie relato, evidência, interpretação e hipótese.
- Registre datas e contexto temporal.
- Trate informações íntimas como confidenciais.
- Revise o sistema sem transformar a manutenção em trabalho excessivo.

## Rotina recomendada
- Durante o dia: capturar sem interromper o pensamento.
- Uma ou duas vezes por semana: processar a Entrada.
- Semanalmente: revisar projetos e compromissos.
- Mensalmente: rever objetivos e áreas da vida.
- Anualmente: revisar linha do tempo e aprendizados.
