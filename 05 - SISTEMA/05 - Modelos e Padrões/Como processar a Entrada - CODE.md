# Como processar a Entrada — CODE

CODE é um fluxo de trabalho, não uma árvore de pastas.

## 1. Capturar
Registre rapidamente sem interromper o pensamento. Não precisa escolher pasta, tag ou título perfeito.

## 2. Organizar
Leia a captura e decida:
- É uma ação ou resultado com começo e fim? → [[01 - PROJETOS/Projetos ativos]]
- É responsabilidade contínua? → [[02 - Áreas da Vida]]
- É material de referência? → [[03 - Recursos]]
- É conteúdo inativo com valor histórico? → [[04 - Arquivo]]
- É uma regra, modelo ou mapa do próprio sistema? → [[05 - SISTEMA/05 - Modelos e Padrões/Manual do Segundo Cérebro]]

Se não souber, mantenha na Entrada e marque para esclarecer.

## 3. Destilar
Extraia o que realmente importa:
- Qual é a ideia principal?
- O que é fato, relato, interpretação ou hipótese?
- Qual contexto precisa ser preservado?
- O que é redundante?
- Há uma ideia duradoura que merece nota própria?

Não apague o registro original quando ele for importante como fonte.

## 4. Expressar
Transforme o conhecimento em algo útil:
- uma decisão;
- uma próxima ação;
- uma nota permanente;
- uma atualização de projeto;
- uma pergunta para investigar;
- uma mudança de plano.

## Encerramento da captura
Após processar, marque como resolvida ou mova para seu destino. Não deixe a Entrada virar um arquivo permanente desorganizado.

## Revisão rápida
- [ ] Entendi o conteúdo?
- [ ] Preservei a origem?
- [ ] Escolhi o destino adequado?
- [ ] Registrei data/contexto quando necessário?
- [ ] Criei apenas links relevantes?
- [ ] Identifiquei o que ainda precisa de confirmação?
