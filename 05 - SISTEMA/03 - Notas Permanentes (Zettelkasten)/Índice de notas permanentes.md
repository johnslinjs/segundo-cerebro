# Índice de notas permanentes

Este índice reúne ideias que tenham valor duradouro, formuladas de maneira clara e conectadas a evidências ou fontes.

## Critérios para criar uma nota permanente
- Uma ideia central por nota.
- Título que expresse a ideia.
- Explicação em palavras próprias.
- Fonte ou contexto de origem.
- Links para ideias relacionadas.
- Separação entre observação e interpretação.

Ainda não promover capturas para notas permanentes sem processamento e validação.
