# CODE — fluxo de conhecimento

CODE significa **Capture, Organize, Distill, Express**.

## 1. Capture — Capturar

Registre ideias, trechos, referências, aprendizados e informações que possam ser úteis. Use [[Inbox/Entrada]] para capturas rápidas. Não interrompa o pensamento tentando classificar tudo imediatamente.

## 2. Organize — Organizar

Mova a captura para o projeto ou área em que será útil. Se não houver aplicação atual, use Resources. Quando deixar de ser ativo, mova para Archives. A organização segue PARA e não uma árvore temática profunda.

## 3. Distill — Destilar

Ao revisar uma nota, destaque o essencial em camadas:
- Negrito ou destaque para a ideia central.
- Resumo curto para a essência.
- Contexto e detalhes preservados abaixo, quando necessários.

O objetivo é facilitar a reutilização sem perder a fonte ou o contexto.

## 4. Express — Expressar

Use o conhecimento para produzir algo: tomar uma decisão, resolver um problema, escrever, ensinar, criar um processo ou concluir um projeto.

## Pergunta de encerramento

Como esta informação pode me ajudar a produzir algo ou agir melhor?
